# CCNA Enterprise Network Setup

## About The Project
This project is a complete enterprise network simulation built using Cisco Packet Tracer. It connects multiple local area networks (LANs) to a simulated internet connection, using industry-standard routing and switching protocols.

## Key Technologies Used
* **Routing:** OSPF (Open Shortest Path First) for dynamic routing
* **Switching:** VLANs and Inter-VLAN Routing (Router-on-a-Stick)
* **IP Services:** DHCP configuration on routers, NAT/PAT (Network Address Translation)
* **Security:** Port Security, Encrypted Passwords, Access Control Lists (ACL)

## Files Included
* `Enterprise_Network.pkt`: The main Cisco Packet Tracer simulation file.
* `Network_Documentation.pdf`: Complete documentation including IP tables, VLAN configurations, and protocol details.
